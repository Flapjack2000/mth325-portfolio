#### Proper Vertex Coloring
A *proper vertex coloring* is an assignment of a color to each vertex in a graph so that no vertex is adjacent to another vertex of the same color. A proper vertex coloring can be referred to as a graph coloring, a vertex coloring, or simply a coloring.
