#### Proper Vertex Coloring
A *proper vertex coloring* is an assignment of a color to each vertex in a graph so that no vertex is adjacent to another vertex of the same color. A proper vertex coloring can be referred to as a graph coloring, a vertex coloring, or simply a coloring.

When a graph can be properly colored with $k \ge 0$ colors, the graph can be called $k$-colorable. Note that if any graph is $k$-colorable, then the graph is also $(k+1)$-colorable.

#### The Chromatic Number of a Graph
The *chromatic number* of a graph $G$, $\chi(G)$, is the smallest integer $l$ so that $G$ is $l$-colorable.

If the chromatic number of a graph $G$ is $k$, then $G$ is $k$-chromatic.

#### Cliques
A clique is a subgraph that is isomorphic to a complete graph. A $k$-clique is a subgraph isomorphic to the complete graph $K_k$ for some positive integer $k$.
